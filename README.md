# CNNard App

A Flutter project combining messaging, news reading, and note-taking in one app, where users can communicate, stay updated with news, and jot down important notes all in one place.

## Features

### - User Registration and Login
- Register and log in with a real email address
- Email verification with a "Verify" button
- Profile setup: Select a profile picture, name, and bio
- Secure login and password recovery options

### - Real-Time Messaging
- Chat with friends in real-time
- Send text messages, photos, and videos
- Group chats and private conversations

### - News Feed
- Read the latest news from reliable sources like CNN
- Explore articles in different categories: World, Politics, Technology, Sports, etc.
- Tap on any article to read more and view the source

### - Note-Taking
- Create and organize notes with titles and text
- Edit and delete notes
- Search for specific notes
- Sync notes across devices if necessary

### - Profile Management
- Update your profile information anytime
- Add a profile picture and bio
- View your past messages, notes, and news articles

### - User Interface
- Easy-to-use interface for chatting, reading, and note-taking
- Dark mode support for comfortable reading in low-light settings
- User-friendly navigation between messaging, news feed, and notes sections

The app serves as a multifunctional platform where you can stay connected with friends, read the latest headlines, and keep track of important ideas in your notes. The email verification ensures a secure user experience, and the app’s simple design allows users to easily switch between the chat, news, and note-taking sections.
